# The Unnatural Arts

Catalogue site for The Unnatural Arts, a family of synthetic acts: Zeroth Law, Chrissie No. 7 and Wren Nightingale. Elephant Island Music.

A single static page, served by GitHub Pages.

## Adding a release

Open `index.html` and find the block marked `EDIT HERE`. Add one entry at the bottom of the `RELEASES` list. The catalogue number comes from the position in the list.

- `youtube`: the video ID (the part after `v=` in the link)
- `substack`: full link to the post, or `""`
- `img`: a file in `assets/thumbs/` (add its key to `THUMBS`), or `""` to use the YouTube thumbnail

Images live in `assets/`.
